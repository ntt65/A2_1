# 단계별 수용 기준

이 문서는 [미션 원문](../A2_1_mission.md)의 요구 사항을 실행 가능한 검증 기준으로 정리한다. 원문과 수학적으로 충돌하거나 해석이 필요한 조건은 [결정 기록](DECISIONS.md)에 근거와 적용 기준을 남긴다. 체크되지 않은 항목은 예정된 검증이다. 문서에 기준이 적혀 있다는 사실은 구현 또는 테스트 통과를 뜻하지 않으며, 체크한 항목의 증거는 해당 작업 이슈와 기록에서 확인한다.

## 공통 기준

- 알고리즘의 수치 계산은 NumPy로 구현한다. 자동 미분·외부 최적화·머신러닝 구현 라이브러리를 사용하지 않는다.
- 모든 함수·클래스에 목적, 매개변수, 입력·출력 shape, 예외를 설명하는 docstring을 작성한다.
- 수식의 기호와 코드의 변수·shape를 대응시킨다. 기본 수치 검증은 `float64`를 사용한다.
- 실행 진입점에서 공통 시드 함수로 `np.random.seed(42)`를 호출한다. import나 개별 수학 함수 호출 시 전역 난수 상태를 재설정하지 않는다.
- 허용오차 비교에서는 절대오차와 상대오차를 구분한다. `assert` 또는 NumPy assertion의 `atol`, `rtol`을 명시하며 Python 최적화 모드로 assertion을 끄지 않는다.
- 유효 입력, 대표 경계 입력, 실패해야 하는 입력을 검증한다. 실패를 숨기거나 허용오차를 임의로 느슨하게 바꾸지 않는다.
- 테스트 결과에는 실행 명령, 환경 버전, 실제 측정 오차, 성공·실패를 기록한다. 미실행 검증은 미실행으로 표시한다.
- 그림은 제목·축·범례·매개변수를 포함한 PNG로 `outputs/`에 저장한다. 수치 검증과 시각적 확인을 분리한다.
- 현재 작업의 테스트·문서·레지스트리와 이슈 기록을 함께 갱신한다. 현재 단계가 끝나기 전에 다음 단계 구현을 시작하지 않는다.

## Step 1 — 공통 유틸리티·캐시·레지스트리

- [x] 안정적인 Sigmoid와 Softmax, 중심차분 공통 함수, 시드 고정, 공통 플롯 기반을 중복 없이 구성한다.
- [x] Sigmoid는 큰 양수·음수 입력에서도 유한한 결과를 반환하고 `sigmoid(0) = 0.5`를 만족한다.
- [x] Softmax는 계산 축을 명시하고 최댓값을 빼서 계산한다. 유효한 유한 입력에 대해 출력 shape을 유지하며 각 확률은 0 이상이고 유한하다.
- [x] Softmax의 각 출력 벡터에 대해 `abs(sum - 1.0) <= 1e-6`을 검증한다. 큰 입력, 음수 입력, 다차원 배열의 지정 축을 포함한다.
- [x] 동일 seed와 동일 실행 조건에서 난수 배열이 재현된다.
- [x] 중심차분 공통 함수는 `f(x)=x²`, `x=3`, `h=1e-5`에서 절대오차 `<=1e-4`를 만족한다. `h<=0` 또는 비유한 `h`는 거부한다.
- [x] 캐시 키는 입력 값·shape·dtype·계산 매개변수·버전을 반영한다. 같은 키의 반복 계산은 재사용되고 입력이나 버전이 바뀌면 구분된다.
- [x] 메모리·디스크 캐시의 저장/복원, 손상 시 재계산, 반환값 변경의 영향, 정리 정책을 검증한다.
- [x] 디스크 캐시는 비신뢰 pickle 역직렬화를 사용하지 않으며, 생성 데이터는 Git에서 제외한다.
- [x] 정방향·역방향 레지스트리는 실제 존재하는 파일·심볼을 가리키고 변경 후 갱신된다. 줄 번호만으로 대상을 식별하지 않는다.
- [x] 색인 누락·불일치 시 범위를 제한한 검색으로 복구할 수 있고, 복구 사실을 기록한다.

Step 1의 중심차분 공통 함수는 이후 Step 3에서 재사용한다. Step 3의 공개 미적분 기능과 시각화 구현을 이 단계에서 앞당기지 않는다.

## Step 2 — 선형대수

### 행렬 변환과 면적

- [x] 단위 원에 회전, 스케일링 `S(2, 0.5)`, 전단을 적용하고 변환 전후를 한 Figure에서 비교한다.
- [x] 점 배열과 행렬의 곱 방향을 명시한다. 예를 들어 점 열벡터 묶음 `P: (2, n)`에 `A: (2, 2)`를 적용하면 `A @ P: (2, n)`이다.
- [x] 면적은 점의 좌표에 대한 다각형 면적 공식으로 계산하여 행렬식 계산과 독립적으로 비교한다.
- [x] 비특이 행렬에서 `abs(area_after / area_before - abs(det(A))) / abs(det(A)) <= 0.01`을 만족한다.
- [x] 특이 행렬은 상대오차로 나누지 않고 단위 원 실험의 면적비 절대오차 `<= 1e-10`을 검사한다. 음의 행렬식은 방향 반전과 양의 면적비를 구분한다.

### Power Iteration

- [x] 반복식 `v_next = A @ v / ||A @ v||₂`와 Rayleigh quotient `lambda = v.T @ A @ v / (v.T @ v)`를 직접 구현한다.
- [x] 입력은 실수 정방행렬과 길이가 맞는 영이 아닌 초기 벡터로 한정한다. 일반 입력에 대한 수렴을 보장한다고 설명하지 않는다.
- [x] 기본 검증 행렬 `[[4, 1], [1, 3]]`, 초기 방향 `[1, 1]`을 사용한다. 기준 고유값은 `(7 + sqrt(5)) / 2`이며 `np.linalg.eig`와도 검증한다.
- [x] 절댓값이 가장 큰 기준 고유값에 대한 상대오차가 `<= 0.05`이고, 정규화한 고유벡터의 norm은 1에 가깝다.
- [x] 검증 행렬에서 상대 잔차 `||A v - lambda v||₂ / (||A||F ||v||₂) <= 1e-6`을 만족한다. 분모가 0인 영행렬은 별도 처리한다.
- [x] 반복 횟수·최대 반복 수·종료 조건·수렴 여부를 반환하거나 추적 가능하게 기록한다. 반복 수를 참고 예시의 51회에 맞추지 않는다.
- [x] 음의 지배 고유값은 부호를 보존한다. 영행렬, 영 초기 벡터, 동일 절댓값의 지배 고유값, 최대 반복 도달 시 동작을 정의하고 검증한다.
- [x] `np.linalg.eig`는 비교 검증에서만 호출한다. 알고리즘 본체에서 호출하지 않는다.
- [x] 이슈 #23 보완: `python -m scripts.verify_power_iteration`이 두 방법의 고유값·고유벡터·상대오차·5% 허용치·판정을 출력한다. 기본 선형대수 실험도 고유값·오차·판정을 콘솔에 표시하고 같은 [실행 보고서](../outputs/power_iteration_eig_comparison.md)와 [JSON](../outputs/power_iteration_eig_comparison.json)을 저장한다. 잘못된 기준값에 대한 실패 검증을 포함한다.

### SVD 이미지 근사

- [x] `A: (m, n)`에 대해 `np.linalg.svd(A, full_matrices=False)`와 `A_k = U[:, :k] @ diag(s[:k]) @ Vt[:k, :]`를 사용한다.
- [x] rank는 정수이며 `1 <= k <= min(m, n)`을 만족해야 한다. 범위를 넘으면 명확히 실패하며 조용히 잘라내지 않는다.
- [x] 64×64 이하 grayscale 본 실험은 유효한 rank를 사용한다. 64×64 입력의 비교 rank는 `10, 50, 64`로 고정한다.
- [x] 별도 합성 128×128 grayscale 보충 실험에서 원문 지정 rank `10, 50, 100`의 복원 결과를 한 Figure에 비교한다. 크기 조건 충돌과 보충 실험의 목적을 명시한다.
- [x] 완전 rank 복원의 상대 Frobenius 오차는 `<= 1e-10`이다. 영 입력은 절대오차로 검증한다.
- [x] rank가 증가할 때 Frobenius 복원 오차는 수치 허용오차 내에서 증가하지 않는다. 화면 표시용 clipping 결과로 이 검증을 대체하지 않는다.
- [x] 저장 원소 수 `k(m+n+1)`와 원본 `mn`을 비교한다. 모든 rank가 저장량을 줄인다고 주장하지 않는다.

## Step 3 — 미적분

- [x] 중심차분 `f'(x) ≈ (f(x+h)-f(x-h))/(2h)`를 공통 유틸리티로 재사용한다.
- [x] `f(x)=x²`, `x=3`, `h=1e-5`에서 `abs(numerical_derivative - 6.0) <= 1e-4`를 만족한다.
- [x] `h`가 양의 유한 수인지 확인하고, 너무 작은 `h`의 반올림 오차와 큰 `h`의 절단 오차를 설명한다.
- [x] `f(x,y)=x²+y²`의 등고선 위에 gradient `(2x, 2y)`를 화살표로 표시한다.
- [x] 원점 이외 표본에서 gradient와 접선 `(-y, x)`의 내적이 0에 가까움을 수치로 확인하고 수직 관계를 시각적으로 점검한다. 원점의 영벡터에 방향을 부여하지 않는다.

## Step 4 — 최적화

- [x] Vanilla GD는 `theta_next = theta - lr * gradient(theta)`로 구현한다.
- [x] Momentum은 초기 속도 0, `v_next = beta * v + gradient(theta)`, `theta_next = theta - lr * v_next`로 통일한다. `beta=0.9`를 사용한다.
- [x] 원형 함수 `x²+y²`, 초기점 `(5,5)`, `lr=0.1`에서 100회 업데이트 후 `||theta||₂ <= 0.1`을 만족한다.
- [x] 궤적은 초기점을 포함하므로 100회 업데이트의 shape은 `(101, 2)`이다. 비교 실험에서 초기점·업데이트 횟수·목적함수를 일치시킨다.
- [x] 원형 함수에서 `lr=0.5`의 한 번 만에 수렴, `lr=1.0`의 비수렴 진동, `lr=1.1`의 발산을 각각 그린다. 원문의 “0.5 이상에서 발산”을 사실로 재현하지 않는다.
- [x] 발산 그림은 유한한 범위에서 종료하도록 반복 횟수를 제한하고 비유한 수 발생을 기록한다. 발산을 일반 실행 오류와 혼동하지 않는다.
- [x] GD와 Momentum의 경로, 목적함수 값, gradient norm을 같은 Figure 또는 비교 가능한 그림에서 확인한다.
- [x] 타원형 함수 `x²+10y²`, 초기점 `(5,5)`, `lr=0.05`, `beta=0.9`에서 두 방법을 비교한다. 필요 시 수렴 범위 안에서 추가 학습률 실험을 하되 모든 설정을 기록한다.
- [x] Momentum의 이점과 진동·초기 과도응답을 실제 측정값으로 설명한다. 모든 단계에서 더 작거나 항상 더 빠르다는 assertion을 두지 않는다.

## Step 6 — 확률·손실·MLE

- [x] 정규분포 표기는 `N(mu, variance)`로 통일한다. `N(0,1)`은 표준편차 1, `N(2,0.5)`는 표준편차 `sqrt(0.5)`이다.
- [x] 두 정규분포 PDF를 같은 Figure에 그린다. 평균·분산을 범례에 명시한다. 각 분포의 `mu±8*sigma` 구간을 10,001개 점으로 나누어 사다리꼴 적분한 값의 1 대비 절대오차 `<=1e-4`와 PDF 비음수성을 검증한다.
- [x] Bernoulli `p=0.3`, `p=0.7`의 PMF를 0·1에서 비교하고 각 확률이 `[0,1]` 범위이며 합의 1 대비 절대오차 `<=1e-12`임을 검증한다.
- [x] Softmax를 공통 모듈에서 재사용하고 출력 합 오차 `<= 1e-6`을 노트북에서도 확인한다.
- [x] 독립 관측, 고정된 양의 공통 분산, `y_i=f_theta(x_i)+epsilon_i`와 Gaussian 오차를 가정하고 `NLL = n/2 * log(2*pi*sigma²) + SSE/(2*sigma²)`를 유도한다.
- [x] 위 가정에서 MLE가 SSE 및 MSE 최소화와 같은 최적해를 갖는 이유를 설명한다. 음의 로그우도가 MSE와 항상 같은 수치라고 쓰지 않는다.
- [x] Bernoulli likelihood의 음의 로그가 BCE임을 유도하고, 다중 클래스 categorical likelihood와 one-hot Cross-Entropy를 별도로 유도한다.
- [x] 합 손실과 평균 손실의 관계 및 로그의 밑(자연로그)을 명시한다. 경계 확률의 `log(0)`를 조용히 무시하지 않는다.
- [x] BCE의 안정적인 logit 표현 `logaddexp(0,z)-y*z`와 해석 gradient `sigmoid(z)-y`의 일관성을 설명한다. 고정 예제의 손계산은 원문의 확률 표현과 연결한다.
- [x] 노트북 전체를 새 실행 상태에서 순서대로 실행하고 수식·출력·그림을 점검한다.

## 보너스 전체 — 이슈 #27

- [x] Adam의 두 모멘트·편향보정·epsilon 위치를 독립 첫 두 단계 기대값과 atol=1e-14, rtol=0으로 확인한다. beta=0·영기울기·reset·반환값 복사·shape 변경·잘못된 설정·overflow·정밀도를 잃는 모멘트 underflow를 검증한다.

- [x] Newton은 유한·대칭·양의 정부호 `(n,n)` Hessian과 `(n,)` 벡터를 사용해 `H*d=g`를 풀고 inverse/eig를 호출하지 않는다. 잘못된 shape·singular·indefinite·nonfinite를 명시적으로 처리한다.
- [x] 양의 정부호 이동 이차함수의 Newton 한 단계 해가 atol=1e-12, rtol=0으로 일치하고 고정 damping·Hessian 중심차분·subnormal/대형 행렬 회귀 검증을 포함한다.
- [x] GD/Momentum/Adam은 같은 시작점·200회·명시한 학습률로 비교하고 경로 `(201,2)`·loss·gradient norm·반경 .1 first/stay 및 미도달 null을 저장한다. Newton/GD는 동일 gradient 종료 기준으로 비교하며 Hessian 비용과 한계를 설명한다.
- [x] 정보 이론 API는 shape·축·유효 분포(sum1 atol=1e-12,rtol=0)를 검증하며 자연로그를 사용한다. 0log0=0과 p>0,q=0의 +inf를 보존한다.
- [x] 균등·점질량·독립 유리확률 상수의 entropy/CE/KL이 atol=1e-14,rtol=0으로 일치한다. 정확히 정규화된 고정 검증 표본의 유한 결과에서 CE=H+KL 오차 <=1e-12, KL>=-1e-14를 확인하고 비대칭·극소확률·경계·축·예외를 검증한다. 합 오차 1e-12를 허용한 모든 입력의 KL 비음수를 보장하지 않는다.
