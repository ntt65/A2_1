## 검토·실패·보완 기록

- 기존 PR #1의 Power Iteration은 고유값 변화만으로 종료하여 동률 고유값에서 큰 잔차를 놓쳤다. 새 구현은 잔차·종료 사유·반복 예산을 노출한다.
- 기존 합성 이미지 rank가 3으로 k별 비교가 거의 같았다. 새 데이터는 질감과 난수를 포함하며 수치 rank64/128을 확인한다.
- 원문의 64×64/k100 충돌은 기존 결정대로 두 실험으로 나누고, 과도한 rank를 조용히 줄이지 않는다.
- 작은 잔차 `1e-200`의 norm 제곱이 underflow해 수렴으로 오판하는 경우를 독립 리뷰에서 재현했다. 최대 절댓값으로 norm을 스케일링하고 회귀 검사를 추가했다.
- 동일 열 특이행렬 `[[7,7],[35,35]]`에서 LU 기반 determinant가 작은 비영값을 남겨 상대오차를 적용했다. 2×2 스케일 조절 `ad-bc`로 정확한 영값을 유지하고 절대오차 분기를 검증했다.
- `diag(1e-200,1e-200)`의 비영 determinant가 underflow하여 성공으로 오인되지 않도록 표현 범위 손실을 명시적으로 거부한다.
- 극단 픽셀값의 Matplotlib 정규화 overflow를 재현하여 표시용 공통 스케일링을 적용했다. 수치 복원과 오차는 원값을 유지한다.
- PNG 시각 검사에서 SVD 제목 첫 줄이 잘린 것을 발견했다. constrained layout과 충분한 높이를 적용하고 64/128 비교 모두 제목 bbox가 캔버스 안에 있는지 회귀 검사했다.
- 초기 SVD 그림 테스트의 수기 기대 오차를 잘못 적은 부분을 독립 대각행렬 이론값 `sqrt(17/98)`로 바로잡았다.

## 범위와 한계

작은 잔차는 고유쌍 정확도이며 임의 초기값에서 지배 고유값을 보장하지 않는다. 비수렴·nullspace는 별도 상태로 반환한다.
SVD rank가 크면 원소 수가 원본보다 늘 수 있으며 이미지 파일 인코딩 압축률을 주장하지 않는다.
노트북과 미적분 본체는 미구현이며, 다음 단계는 [Step 3 이슈 #6](https://github.com/ntt65/A2_1/issues/6)이다.
